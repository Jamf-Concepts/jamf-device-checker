# Contributing to Jamf Device Checker

Thanks for your interest in improving Jamf Device Checker!

## This is a stub repository

This repository contains no source code — it exists as an issue-tracking hub for the Jamf Device Checker app on the Apple App Store. The app itself is developed internally by the Jamf Concepts team.

## How to contribute

### Report a bug
Open a [bug report](../../issues/new?template=bug_report.yml) and describe what you observed, what you expected, and how to reproduce it.

### Request a feature
Open a [feature request](../../issues/new?template=feature_request.yml) with context on the problem you're trying to solve.

### Ask a question
Open a [general question](../../issues/new?template=general_question.yml).

## Documentation

Documentation — guides and release notes live on the [Jamf Concepts site](https://concepts.jamf.com/en/guides/jamf-for-mobile/jamf-device-checker/). If you'd like to suggest a documentation change, open an issue describing what should be updated.

## Code of Conduct

Be respectful and constructive. Issues that are abusive or off-topic may be closed without response.
