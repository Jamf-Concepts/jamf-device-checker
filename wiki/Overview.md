# Overview

## Key Features

- **Readiness Dashboard** — A single visual view of device health so users can tell in seconds whether they're good to go or need to take action.
- **OS Version Status** — Confirms the device is on a supported iOS version and surfaces upcoming update deadlines before they become blockers.
- **Required Apps Check** — Verifies that admin-specified work apps are installed and up to date, eliminating "why doesn't this app work?" tickets.
- **Battery, Power & Thermal** — Monitors battery health, current charge, and thermal state so users know when heat or a low charge may impact their day.
- **Storage Monitoring** — Shows available storage with warning and critical thresholds so users can free space before it becomes urgent.
- **Network Connectivity** — Confirms Wi-Fi and cellular are active and optionally runs a live internet reachability test.
- **Performance Monitoring** — Tracks memory and CPU usage to help identify slowdowns before they impact productivity.
- **Jamf Setup Integration** — Optionally displays on-duty / off-duty status at the top of the app when your organization uses Jamf Setup.
- **Fully Managed** — Every check, threshold, and branding element is configured through Jamf Pro's Managed App Config — no user setup required.

## Use Cases

| Use Case | Description |
|---|---|
| Shared-device readiness | Frontline workers, retail, and healthcare staff verify shared iPads are charged, updated, and ready before a shift. |
| BYOD / corporate device self-service | End users get a self-service readiness view that reduces "is my device compliant?" support tickets. |
| Field readiness | Field technicians confirm connectivity, required apps, and battery before leaving for a job site. |
| Update campaigns | Admins push a minimum OS version and deadline; users see exactly what's needed and when. |
| Setup / duty status | Organizations using Jamf Setup surface duty status alongside device health for a single-glance check. |
